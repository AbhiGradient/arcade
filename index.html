ABOUT

Pixel Vault is a static launcher for a collection of browser games. Each game lives in its own folder and runs as its own page, so keyboard, mouse, audio and pointer-lock behave exactly as the game intends.

Choose a card, press play, and the game opens in this tab. Use your browser’s back button to return to the arcade, or use a return link if the game provides one.

Tip: press / to jump to search. Sound, CRT scanlines and animated effects can each be switched off from the top bar.
